# Python library for automated single crystal refinement and reporting with Shelx and Platon

Authors: E. Antono, J. Ling, and B. Selvaratnam

# Crystal Refinement Tools

A suite of Python tools designed to assist with single-crystal X-ray diffraction refinement automation, structure standardization, data processing, and publication-quality report and figure generation.

## Features

The package provides several command-line interface (CLI) scripts to handle various stages of crystallographic analysis:

## 1. Single Crystal Refinement (`cr-refine`)
- **Function:** Automate many of the steps in single crystal refinement.  It automatically detects split occupancy, deficiency, wrong element assignments, and anisotropy.  
- **Output:** Generates top 10 new `.cif` file with sultions from the automated refinement.
- **Usage:**
  ```bash
  cr-refine -c minimal.yml -d examples/ -i input -o test
  ```

The optimization package can be run using a command line interface and configuration file. Run `cr-refine -h`
to see the help menu for the command line interface.

To run an example optimization on the ins file in the example folder, change the `path_to_xl` and `path_to_xs` values
in the `minimal.yml` file to correspond to the path of the SHELX executables on your machine. 
The results of the optimization will be output to the `examples/optimizer_results` directory. `0.res` is the highest
scoring result file, `optimization_graph.pdf` is the optimization graph generated by graphviz, and `report.txt` will
contain metadata on the optimization process.

See `config.yml` for further documentation of the configuration file parameters.

The optimization package can also be used directly in python by creating an instance of the `Optimizer` object and
using the `run()` method.

#### How it works

The optimizer tries the following steps in order:
1) Identify crystal sites (try adding or removing Q peaks)
2) Switch elements at each crystal site
3) Try site mixing at each site
4) Try partial occupancy at each site
5) Try extinguishing
6) Try anisotropy 

At each step, the optimization takes into account both the fit R1 value as well as the bond lengths.
The ideal bond lengths can be determined by 3 different methods:
1) User input via the bond_length argument to the Optimizer class
2) A machine learning model for bond length hosted at citrination.com.  To use this model, the user must have a free
account on the public Citrination site.
3) Atomic radii of the elements

The optimizer will follow multiple paths to see which path yields the best final fit.  For example, if two different
elements both yield similar R1 values at a given crystal site, the optimizer will try both options to see which give
the best final fit.  This results in a branching tree structure.

## 2. PLATON Standardization (`cr-standardize`)
Automates the use of PLATON's `stidy` utility to standardize CIF files. This tool helps correct unit cell parameters, symmetry settings, and site occupancies based on PLATON's recommendations, ensuring compliance with journal standards (e.g., IUCr).

- **Function:** Runs PLATON `stidy` on a given `.cif` file.
- **Output:** Generates a new `_standardized.cif` file with updated cell parameters and site data.
- **Usage:**
  ```bash
  cr-standardize input.cif [--platon-executable platon]
  ```

## 3. Crystallographic Report Generation (`cr-report`)
Generates comprehensive, publication-ready Word documents (`.docx`) from refined CIF files. The report includes:

- **Crystal Data Table:** Formula, space group, unit cell parameters, volume, Z, temperature, density, crystal dimensions, absorption coefficient, theta limits, and data statistics.
- **Atomic Coordinates Table:** Lists site labels, Wyckoff positions, fractional coordinates (x, y, z), occupancy, and equivalent isotropic displacement parameters ($U_{eq}$).
- **Coordination Environment Table:** Displays interatomic distances ($d$), coordination numbers (CN), and deviation values ($\Delta$) based on atomic radii. Neighbors outside the defined CN are highlighted in grey.
- **Formatting:** Supports complex LaTeX-to-OMML conversion for space groups and proper subscript/superscript formatting for chemical formulas and physical constants (e.g., $R_1$, $wR_2$, $\mu$, $\Delta\rho$).

- **Usage:**
  ```bash
  cr-report input.cif
  ```

## 4. Site Plots & Supercell Visualization (`cr-plot_sites`)
Creates high-resolution PNG images of crystal structures using PyVista. This tool visualizes:

- **Supercell Representation:** Displays a $2 \times 2$ grid of unit cells to show connectivity and coordination environments clearly.
- **Disorder Handling:** Automatically detects mixed occupancy sites (disorder) and renders atoms with split spheres proportional to their occupancies, colored by element type.
- **Coordination Polyhedra:** Draws convex hulls around central atoms based on their coordination number, highlighting nearest neighbors.
- **Customization:** Allows user-defined camera positions, tilt angles, atom scaling factors, and font sizes. Supports user-defined colors and CN preferences via external text files (`colors.txt`, `CN.txt`).

- **Usage:**
  ```bash
  cr-plot_sites input.cif \
    [--ncols 2] \
    [--rscale 0.3] \
    [--fontsize 100] \
    [--cam-dist 50] \
    [--cam-tilt 5] \
    [--width 8000] \
    [--height 8000] \
    [--cam-pos '[100, 5, 5]']
  ```

### 5. Interactive CN & Color Selection (`cr-select_CNs`)
An interactive tool to determine optimal Coordination Numbers (CNs) and atom colors for visualization purposes.

- **Phase 1: CN Selection:** Computes potential coordination numbers using the $d/d_{min}$ gap method. Prompts the user to select the appropriate CN for each unique site, saving results to `CN.txt`.
- **Phase 2: Color Selection (Optional):** If invoked with the `--colors` flag, prompts the user to assign web-compatible colors to each element type, saving results to `colors.txt`. These preferences are automatically used by `cr-plot_sites`.

- **Usage:**
  ```bash
  cr-select_CNs input.cif [-c | --colors]
  ```

## Installation

Install the package using pip:

```bash
pip install crystal_refinement
```

## Dependencies

The package relies on several scientific Python libraries:
- `numpy`, `scipy`: Numerical computation and spatial analysis.
- `pandas`: Data manipulation for CIF parsing and reporting.
- `cifkit`: Advanced CIF file reading and structure connection analysis.
- `pyvista`: 3D visualization and plotting.
- `python-docx`: Word document generation.
- `uncertainties`: Propagation of errors in crystallographic parameters.

## Usage Examples

### Automated Refinement
```bash
cr-refine -c minimal.yml -d examples/ -i input -o test
# Output: optimizer_results/0.cif 
```

### Standardizing a CIF File
```bash
cr-standardize my_structure.cif
# Output: my_structure_standardized.cif
```

### Generating a Publication Report
```bash
cr-report my_structure_standardized.cif
# Output: crystal_structure_data_Formula.docx
```

### Creating a Visual Supercell Plot
First, define CNs and colors interactively:
```bash
cr-select_CNs my_structure_standardized.cif --colors
```
Then, generate the plot:
```bash
cr-plot_sites my_structure_standardized.cif --width 3000 --height 3000
# Output: supercell_pyvista.png, supercell_pyvista_tilt.png
```

# Installation:

Clone this git repo:
```sh
git clone git@github.com:CitrineInformatics/crystal-refinement.git
```
Then, use:
```sh
cd crystal-refinement
pip install .
```
to install python dependencies and the crystal structure refinement package. We recommend that this step is done in a
python virtual environment (https://virtualenv.pypa.io/en/stable/).

# Other Dependencies:

- SHELXTL executables (xl.exe and xs.exe on Windows, shelxl and shelxs on MacOS/Linux).
- Platon executable (platon.exe on Windoes, platon on MacOS/Linux)
- Graphviz to render the optimization graphs: https://graphviz.gitlab.io/download/
